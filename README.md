# Mentaur Website 2026

Marketing and campaign landing page for [Mentaur](https://mentaur.co) — the executive mentorship platform.

## Structure

```
mentaur-website/
├── index.html        # Main HTML
├── css/
│   └── styles.css    # All styles
├── js/
│   └── main.js       # All interactivity
└── README.md
```

## Running locally

No build step required. Open `index.html` directly in a browser, or use a simple local server:

```bash
npx serve .
```

## Deployment

This is a static site. It can be deployed to GitHub Pages, Netlify, Vercel, or any static host.

### GitHub Pages

1. Go to repo Settings > Pages
2. Set source to `main` branch, root folder
3. Save — the site will be live at `https://<username>.github.io/<repo-name>`

## Fonts

Loaded from Google Fonts: Playfair Display and DM Sans. An internet connection is required for fonts to render correctly.
